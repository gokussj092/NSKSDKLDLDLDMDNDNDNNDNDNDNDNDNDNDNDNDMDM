## Observación y recuperación estática

Esta última implementa dos GET públicos independientes, Accept:application/octet-stream, límite8MiB: servr_speigosx_sv5c para propósito1/Servers y user_speigo_sv5c para propósito2/Usuarios, ambos bajo el directorio speigo de apksdemons/apks2 en raw.githubusercontent.com. No usan cuenta, cookie, token o sesión remota. URLs exactas y hashes de fuentes en tools/probe.py y generated/recipe.json. No se cambia a URLs de aplicaciones parecidas.

## Pruebas e integración

Un oráculo propio independiente usa JCA para HMAC/AES/rotación y libsodium1.0.18 del sistema para firma/AEAD. No importa el decodificador operativo. Compara todos los objetos, listas, tipos y campos contra Python; el worker real y el CLI fuera del checkout coinciden también. Se verificaron ambos remotos y ambos assets, sin usar metadatos visibles como sustituto del contenido cifrado. RESULTADOS y hashes se conservan en generated/; ningún perfil real, cuenta, APK/SO, DEX ni fuente decompilada se publica.

Entradas públicas: speigo-vpn-configs («SpeiGo VPN · Configuraciones») y speigo-vpn-ssh («SpeiGo VPN · Usuarios SSH»). Mantienen fuentes, validación de propósito, mantenimiento y controles independientes; el fallo de una no obliga a descargar la otra. Se conservan todos los campos de Usuarios, no solo IP/user/password. Icono raster original192x192 del APK. TLS, DNS/IP pública, denegación total de redirecciones y versiones monotónicas se mantienen. No hay cambios Android, compilación APK, merge main, sesión VPN o despliegue VPS; no se certifican archivos/exportaciones de teléfono.
