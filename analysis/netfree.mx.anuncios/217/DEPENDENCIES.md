# Dependencias

Linux x86_64. Python3.12.14 y PyCryptodome3.23.0 en el runtime; JCA/OpenJDK,
Androguard4.1.4, Pillow13.0.0, Loguru0.7.3, PyELFTools0.33, Capstone5.0.9 y
JADX1.5.6 en investigación; Node24.22.1, curl8.5.0, ripgrep y bash para pruebas
y adquisición. Versiones efectivas, origen oficial, licencias declaradas,
dependencias y fuentes compartidas exactas están en el lock y MANIFEST.

Androguard/JADX: Apache2.0; PyCryptodome: BSD/dominio público; Loguru: MIT;
Pillow: MIT-CMU; PyELFTools: dominio público; Capstone: BSD; CPython: PSF;
OpenJDK: GPL2 con Classpath exception; Node: MIT/componentes; curl: curl.
Son licencias declaradas, no una aprobación jurídica para ejecución automática.

Se reinstalaron las42 versiones fijadas tras recuperar el entorno. El lock
conserva41 hashes de distribución de referencia del expediente HTTP Conexión
solo con nombre/versión coincidentes. No se afirma que el archivo de cada
reinstalación se haya vuelto a medir: su procedencia se declara explícitamente.
Un paquete sin archivo conservado queda UNKNOWN. No se ejecutaron o validaron
por separado todas las transitivas. No se instaló ni usó Unicorn.

Fuentes únicas compartidas: inspect_apk.py, decompile.py, elf_inspect.py,
dependency_inventory.py y codec/field_names de HTTP_FenixVPN; sin modificarlas.
Se leyeron TurboMX/SuperFlash como referencias de estructura en la primera
sesión, sin usar sus claves ni importarlos en este método.

Servicios conectados de Git, web y entrega privada: versión no expuesta,
términos del servicio, no redistribuidos ni dependencias del codec.
No se incorporan APK, SO, JAR, wheels ni código decompilado ajeno a Git.
La revisión central de licencias/fase7 y el validador CI están pendientes.
