# Dependencias utilizadas

Python 3.12; pycryptodome 3.23.0 (PyPI, criptografía de formatos existentes); argon2-cffi 25.1.0 (PyPI, implementación nativa RFC 9106); msgpack 1.2.4 (PyPI). Dependencias directas fijadas por requirements.txt; no se añaden nuevas dependencias de producción. Node y npm usan cloud/web/package-lock.json, Next 16.4.3 y sharp 0.35.5 ya declarados. Herramientas propias: build_registry.py, supplied_bridge.py y los tests referenciados en MANIFEST. Sin APK nuevos, instrumentación, hooks ni binarios redistribuidos.
