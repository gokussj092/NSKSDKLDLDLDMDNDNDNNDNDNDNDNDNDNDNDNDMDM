# LITRON VPN

Integración de catálogo de com.fleet.vpn /3.5.9 /25. [Expediente y herramientas](../../../../analysis/com.fleet.vpn/25/RESULTS.md). Fuente pública revisada, parser Unicode/Base64/AES-CBC sin recortar símbolos. Devuelve todas las listas, claves y metadatos; remoto real8 servidores/86 redes, paridad completa con JCA, script aportado y worker.

CLI sin argumentos descarga; archivo o --stdin trabajan sin red. run(bytes) es puro. Python3.10+ y PyCryptodome3.23.0; se reutilizan los validadores JSON de BD_NET_VPN/codec.py. No instala dependencias al ejecutar. Input5MiB, output4MiB, profundidad64 y JSON estricto; errores sin resultados parciales. CBC no autentica datos.

Icono aportado conservado sin edición,288×288/86055bytes. Solo app base: no incluye Litron Pro, archivos, texto ni exportadores. La habilitación y mantenimiento respetan los controles existentes del operador. Todo ocurre en el servidor; no requiere nueva APK de SP-DECODE.
