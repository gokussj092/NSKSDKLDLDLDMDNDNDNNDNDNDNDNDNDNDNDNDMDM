Catálogo remoto e incluido de com.litron.udp, versión11.0/build11. Proveedor independiente litron-pro-vpn; no confundir con Litron VPN base com.fleet.vpn. [Método, herramientas, versiones, pruebas y limitaciones](../../../../analysis/com.litron.udp/11/ANALYSIS.md).

La validación real conserva el JSON completo de51 servidores/206 campos internos, comparado con Java/JCA independiente y el worker aislado. El asset incluye26 servidores. El lector conserva claves/tipos/campos desconocidos y Json como cadena; falla ante corrupción o límites, sin entregar resultados parciales. CBC no ofrece autenticación criptográfica.

server_catalog_decoder.py acepta archivo, --stdin o descarga explícita desde la fuente fija documentada. run(bytes) no usa red. No se certifican archivos/texto/exportación de teléfono. El icono PNG500x500 es el original del APKS aportado, sin modificación.
