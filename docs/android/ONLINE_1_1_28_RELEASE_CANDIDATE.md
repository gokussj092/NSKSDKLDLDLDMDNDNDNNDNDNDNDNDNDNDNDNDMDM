- Catalog: Android settings selects a single persisted boolean; default full download. No automatic capability probe or switch during a transfer. Chunk mode uses the existing authenticated manifest/chunk protocol and journal. Both modes preserve the last verified snapshot on failure; select the alternate mode manually. Server defaults chunk support on; explicit VPS env override wins. Real failure diagnostics still require affected device error codes.

API and 30-day ad-free checkout use server-owned currency prices and configured provider list, authenticated quote/version, explicit terms checkbox and provider-host allowlist. One product per checkout; no embedded card collection. Stripe/PayPal USD/MXN/EUR as configured, Mercado Pago MXN. External checkout UI not enabled on Play AAB; no live transactions tested. APK-analysis credits remain gated by server delivery readiness; native credits cart is not a complete checkout.

No automatic change to VPS credentials/flags from this commit. Existing clients see updated server prices on reopening store; this candidate adds native API purchase. Confirm purchases only via verified server callbacks and account entitlements.

Keep Unity test configuration while QA; before public launch verify consent, app-ads.txt, ad unit mapping, payouts and policy compliance. Turn off global forced test mode on Unity Monetization Android project and stop forced testing in LevelPlay; retain actual test devices for development. No Unity dashboard access or live ad validation from GitHub CI. This is an external signed APK release candidate, not a published final or Play AAB.
